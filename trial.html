Learn HTML concepts with simple code examples

HTML Introduction

HTML stands for HyperText Markup Language. It is used to create the structure of web pages.

1. HTML Heading

HTML provides six levels of headings from h1 to h6.

HTML Code 

<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

Output

Heading 1

Heading 2

Heading 3

Heading 4

Heading 5
Heading 6

Example 1


<h1>Welcome to My Website</h1>

Example 2


<h2>About Us</h2>

Example 3


<h3>Our Services</h3>

2. HTML Paragraph

The paragraph tag is used to display text in paragraph format.

HTML Code 

<p>
    This is my first HTML paragraph.
</p>

Output

This is my first HTML paragraph.

Example 1


<p>Welcome to HTML.</p>

Example 2


<p>HTML is easy to learn.</p>

Example 3


<p>I am learning web development.</p>

3. HTML Link

The anchor tag is used to create links.

HTML Code 

<a href="https://www.google.com">
    Visit Google
</a>

Output

Visit Google

Example 1


<a href="about.html">
    About Us
</a>

Example 2


<a href="contact.html">
    Contact Us
</a>

Example 3


<a href="mailto:test@gmail.com">
    Send Email
</a>

4. HTML Image

The img tag is used to display images.

HTML Code 

<img
    src="image.jpg"
    alt="Sample Image"
    width="200">

Output

Example 1


<img src="flower.jpg" alt="Flower">

Example 2


<img src="logo.png" alt="Company Logo">

Example 3


<img src="profile.jpg"
     alt="Profile Picture"
     width="150">

5. HTML Button

The button tag is used to create buttons.

HTML Code 

<button>
    Click Me
</button>

Output

Example 1


<button>Submit</button>

Example 2


<button>Login</button>

Example 3


<button>Register</button>

6. HTML List

HTML provides ordered and unordered lists.

HTML Code 

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Output

  • HTML
  • CSS
  • JavaScript

Ordered List


<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>

Unordered List


<ul>
    <li>Apple</li>
    <li>Mango</li>
    <li>Orange</li>
</ul>

7. HTML Table

The table tag is used to create tables.

HTML Code 

<table border="1">

    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>

    <tr>
        <td>Pooja</td>
        <td>25</td>
    </tr>

</table>

Output

Name Age
Pooja 25

Example 1


<table border="1">

    <tr>
        <th>Name</th>
        <th>City</th>
    </tr>

    <tr>
        <td>Pooja</td>
        <td>Mysuru</td>
    </tr>

</table>

8. HTML Form

Forms are used to collect information from users.

HTML Code 

<form>

    <label>Name:</label>

    <input type="text">

    <br><br>

    <button type="submit">
        Submit
    </button>

</form>

Output



Example 1


<input type="text"
       placeholder="Enter your name">

Example 2


<input type="email"
       placeholder="Enter email">

Example 3


<input type="password"
       placeholder="Enter password">
